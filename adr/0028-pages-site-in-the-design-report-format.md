# 28. The Pages site is a design report in the tailsitter format (amends ADR-0022)

Status: Accepted (2026-11-26)

## Context

ADR-0022 published the README as the front page, the ADRs and a bare list
of rendered notebooks under `notebooks/`. The owner wants the results of
all notebooks on GitHub Pages in the same format as
`onurtuncer/tailsitter-uav-design`: a design report generated from the
pipeline's own notebook list, with the notebooks at the site root.

## Decision

- **`index.html` is a design report**, generated by `scripts/build_site.py`
  from `NOTEBOOK_ORDER` (the list the pipeline executes): the README's
  opening text, the notebooks in run order titled by their own first
  markdown heading, the figures the notebooks wrote, the YAML handoffs,
  and links to the decisions and the source. Adding a notebook to
  `NOTEBOOK_ORDER` is the only edit needed for it to run and appear.
- **Each executed notebook is rendered at the site root** as
  `<notebook>.html`, not under `notebooks/`.
- **Figures and handoffs are published as files**: `img/*.png` from
  `notebooks/figures/` and `out/*.yaml`, so every notebook's results are
  on the site next to the notebook that made them.
- **The README stays a page of its own** (`readme.html`) and the ADRs stay
  under `adr/`. The index adds no content that is not in the README, the
  ADRs or a notebook (ADR-0022): it is generated structure.
- Still only `design-pipeline.yml` deploys, on `main`.

## Consequences

- A notebook that writes a figure or handoff gets it published without
  further edits.
- Figure captions are the file names; a notebook that wants a better
  caption names its figure accordingly.
- The tailsitter site also carries a 3D viewer and bill of materials;
  nothing in this study corresponds to them yet.
- A final `design_summary` notebook (ADR-0021, notebook 13) is not built
  yet; when it is, it lists last like the tailsitter one.
